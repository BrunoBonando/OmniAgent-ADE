OmniAgent Privacy Policy

Last updated 30 August 2026

OmniAgent is a developer tool that runs on your Mac. Your code, your conversations with coding agents and the index built from them stay on your Mac. The only thing the app sends anywhere is your account profile, and only if you choose to sign in.

What stays on this Mac

All of the following is written to ~/Library/Application Support/OmniAgent-ADE and is never transmitted by OmniAgent:

  • Your project files. OmniAgent reads the folders you open. It does not copy them anywhere.
  • The brain index (brain.db) — a local SQLite database of file paths, symbols and text extracted from the folders you open, so that search works. It is rebuildable from your files at any time.
  • Markdown memory (brain/) — the durable notes the app keeps per project. Plain files you can read, edit or delete yourself.
  • Terminal transcripts (transcripts/) — what your agent sessions printed, kept so a session can be reviewed after it ends.
  • Usage analytics — counts and durations the app derives from its own activity (sessions started, time active per hour) for the readout in Settings. Computed on this Mac, stored in brain.db, sent nowhere.

Secret redaction runs before anything is written to transcripts or memory: text matching common credential shapes is replaced with [redacted]. It covers api_key/token/secret/password assignments, HTTP Bearer values, AWS access key ids (AKIA…) and sk--prefixed API keys. That is a safety net, not a guarantee — a secret in a shape it does not recognise will be written as it appeared. Treat this folder as you would treat your shell history.

What the OmniAgent account sends

Signing in is optional. If you do sign in, the app talks to the OmniAgent API at api.omni-agent.ai and the following is involved:

  • Your email address, name and profile picture URL, as supplied by the sign-in provider you chose, are held on your OmniAgent account and returned to the app so it can show who is signed in.
  • A refresh cookie, set by the server and stored by the system cookie store, so you stay signed in across restarts. A short-lived access token is held in memory only.
  • Your GitHub handle, if you connect GitHub in Settings › Accounts.

Nothing else leaves the app: no source code, no terminal output, no transcripts, no memory, no search queries, no analytics. If you choose Continue without signing in, the app makes no account requests at all.

Third-party tools you run

OmniAgent starts coding agents that you install yourself — Claude Code, Codex, GitHub Copilot, AntiGravity and any shell command you type. The moment you start one, that tool talks to its own provider over its own connection, under that provider's terms and privacy policy, using your own credentials for it. Whatever you send it is between you and that provider. OmniAgent only launches the process and shows you its terminal; it does not proxy, inspect or forward the traffic.

Browser panes

A browser pane loads the URLs you ask it to and behaves like a browser: cookies and site data belong to the sites you visit, and files you download land in ~/Downloads. OmniAgent does not track your browsing or send it anywhere.

Your choices

  • Do not sign in. Choose Continue without signing in at launch and the app never contacts the OmniAgent API.
  • Log out. Settings › Accounts. This clears the local session and revokes the server-side one.
  • Delete your account. Settings › Accounts. This permanently removes your account and its data from the OmniAgent API.
  • Delete the local data. Removing ~/Library/Application Support/OmniAgent-ADE deletes the index, memory and transcripts. The index rebuilds itself from your files; nothing there is needed to run the app.
  • Stop the background helper. The terminal daemon that keeps your sessions alive between launches is registered as a login item, and can be turned off in System Settings › General › Login Items & Extensions.

Children

OmniAgent is a developer tool and is not directed at children under 13.

Changes

If this policy changes, the updated version ships with the app release it applies to and is dated at the top of this page.
