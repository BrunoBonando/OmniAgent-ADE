Current artifact is not MAS-ready

The app is intentionally built as a direct-download Developer ID app. The biggest blocker is not polish; it is architecture: unsandboxed terminal execution, a persistent PTY daemon, broad local file access, and third-party agent launching.

Likely approval path

1

Create a separate Mac App Store target/build configuration instead of submitting the current direct-download app.

2

Enable App Sandbox and redesign every feature that depends on unrestricted process, file, socket, or helper access.

3

Remove in-app installer scripts and arbitrary PATH-spawned agents from the MAS build, or move them behind a user-installed external companion with clear boundaries.

4

Add reviewer-facing disclosures: privacy policy, test account, account deletion, provider disclaimers, and exact data-flow explanations.
