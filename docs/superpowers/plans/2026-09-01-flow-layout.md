## Task 2 — `PageShellView` (spec §5)

Files: new `macos/OmniAgent/PageShell.swift`, new `macos/OmniAgentTests/PageShellTests.swift`, pbxproj.

API:
```swift
final class PageShellView: NSView {
    init(title: String, tabs: [String] = [], body: NSView)
    let titleField: NSTextField
    private(set) var tabButtons: [ShellRowView]        // one per tab; accessibility label = tab title; onPress selects + fires
    private(set) var selectedTab: Int                  // 0 by default
    var onSelectTab: ((Int) -> Void)?
    func select(tab: Int)                              // moves the underline; fires nothing
    var trailingAccessory: NSView? { didSet }          // replaces the previous; trailing edge, centred on the title
    let scroll: ShellScrollView                        // hosts `body`; no fade, no inset
    let underline: NSView                              // 2pt, ShellPalette.ink, under the selected tab (test seam)
    let header: NSView                                 // the title/tabs/rule block
}
```
- Metrics: 32pt top padding, 40pt sides. Title `ShellFont.ui(24, .semibold)` in `ShellPalette.ink`. Tab strip 14pt under the title: `ShellFont.ui(14, .medium)`; selected tab label `ink`, others `inkTertiary`; tabs 24pt apart; the underline 2pt tall, the width of the selected label, 8pt under it; a 1pt `ShellPalette.hairline` rule directly under the strip spanning the header's content width. With no tabs: the rule sits 16pt under the title.
- `body` is the scroll view's document; the scroll fills the width under the header with 40pt side padding and 24pt top padding, bottom 24. The scroll is a `ShellScrollView(documentView: body)` (no `topFade`, no `topInset`).
- Tabs animate nothing (no motion needed).
- Tests (`PageShellTests`): the title reads back; pressing tab 1 fires `onSelectTab(1)` and moves `underline` under `tabButtons[1]` (compare `midX` after `layoutSubtreeIfNeeded`); `select(tab:)` moves it without firing; the accessory's `maxX` sits at `header.maxX − 40`; an offscreen render at 1200×800 (`bitmapImageRepForCachingDisplay`) has non-zero size and, under `PANE_RENDER_DIR`, is saved as `page-shell.png` (copy the `saveRenderForInspection` helper `HomeViewTests` has).
